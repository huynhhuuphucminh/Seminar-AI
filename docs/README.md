# docs

Supporting material. The report in the repository root (`Report.pdf`) is the authoritative document; the files here are the working material behind it.

| Folder | Content |
|---|---|
| `assignment/` | The assignment sheet (`S01_Seminar_PSO.pdf`) and the course information issued by the lecturer (`course_information_vi.docx`, original document in Vietnamese) |
| `notes/` | Reading notes on the two papers (`notes_Kennedy_Eberhart_1995.md`, `notes_Poli_2007.md`), symbols and the comparison with Hill Climbing (`formulas_and_hill_climbing.md`) and the one-dimensional hand calculation (`hand_worked_example_1d.md`) |
| `drafts/` | Early Markdown drafts of the report sections (`report_*.md`) and experiment tables (`simulation_tables.md`, `comparison_tables.md`, `local_optimum_analysis.md`) |
| `review/` | Points checked when assembling the first report (`merge_checklist.md`) and the rubric self-assessment (`rubric_self_assessment.md`) |
| `slides_notes/` | Slide outlines (`slide_outline_member*.md`) and Q&A practice lists (`qa_practice_member*.md`), one per member |
| `ai_log/` | The prompt set and the AI-use log of each member (see [`ai_log/README.md`](ai_log/README.md)) |
| `archive/` | The first assembled Word report and its PDF (`Report_v_max_2.0.docx`, `.pdf`), kept for reference |

**Note on numbers.** The drafts, notes, review lists and slide notes were written when the experiments used the velocity limit `v_max = 2.0`. The experiments and the report were later re-run with `v_max = 10.24` (the domain width), so numbers in these files may differ from `Report.pdf`; each file says so at the top where it matters. Links inside these files point to the current layout (`notebooks/`, `results/`, `figs/`).
