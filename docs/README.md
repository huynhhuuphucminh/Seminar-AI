# docs

Supporting material. The report in the repository root (`Report.pdf`) is the authoritative document; the files here are the working material behind it.

| Folder | Content |
|---|---|
| `assignment/` | The assignment sheet (`S01_Seminar_PSO.pdf`) and the course information (`ThongTinMonHoc.docx`) |
| `notes/` | Reading notes on the two papers, the comparison of update formulas and the hand-worked one-dimensional example |
| `drafts/` | Early Markdown drafts of report sections and experiment tables |
| `review/` | List of points checked when assembling the report, and the rubric self-assessment |
| `slides_notes/` | Slide outlines and difficult-question lists, one per member |
| `ai_log/` | Log of the AI tools used (prompt, output, checks made) |
| `archive/` | Earlier versions kept for reference: the first Word report and the per-folder READMEs from the old layout |

**Note on numbers.** The drafts, notes and review lists were written when the experiments used the velocity limit `v_max = 2.0`. The experiments and the report were later re-run with `v_max = 10.24` (the domain width), so numbers in these files may differ from `Report.pdf`. `archive/BaoCao_Seminar_PSO_v_max_2.0.docx` and `.pdf` are the earlier report with the old setting. Relative links inside the Markdown files refer to the old folder layout and may not resolve.
